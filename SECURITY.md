# Security Policy

## Supported scope

This repository is a demo stack and is maintained on a best-effort basis.
Security reports are still welcome for all components in this repository.

## Reporting a vulnerability

If you discover a security issue, please:

1. **Do not** open a public issue with exploit details.
2. Report privately by contacting the repository owner.
3. Include:
   - affected component(s)
   - reproduction steps
   - impact assessment
   - suggested remediation (optional)

## Response expectations

- Initial acknowledgement target: within 7 days.
- Remediation timeline depends on severity and maintainers' availability.

Thank you for helping improve the safety of this project.
